# Task 2 – Cloud Security Audit & Backup

Internee.pk Cybersecurity Internship

## Objective
Ensure Internee.pk's cloud-based platforms follow industry-standard security measures — auditing cloud accounts, applying IAM policies, setting up multi-region backups, and enabling a Web Application Firewall (WAF).

## What's in this repo
- **Task2_Cloud_Security_Report_Updated.docx** – Full write-up covering the cloud security audit, IAM role assumption, WAF log analysis, multi-region backup setup, and AWS Open Data review

## What was done
1. **IAM Enumeration & Role Assumption** – Practiced privilege escalation via role assumption in a guided lab environment.
2. **WAF Log Analysis** – Investigated logged attacks, filtering by Rule ID and timestamp to identify malicious requests.
3. **Multi-Region Backups** – Documented S3 Versioning + Cross-Region Replication (CRR) configuration for data redundancy.
4. **CloudTrail Logging** – Documented how account-level API activity is recorded and investigated using CloudTrail Event History.
5. **AWS Open Data Registry** – Reviewed public datasets available on AWS, including Common Crawl.

## Note
A live, billable AWS account wasn't available for this task, so the multi-region backup and CloudTrail sections are documented conceptually with the exact configuration steps, based on hands-on IAM/WAF work completed in a guided lab environment.
